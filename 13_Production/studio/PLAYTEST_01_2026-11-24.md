## Keep (the owner liked these)
Main menu, New Game confirmation, character creator, Rising Cut, Air Slash, Guard Break, the slimes, the trees and roads.

## Plan
1. **Phase 1, essentials.** Done in code: pause menu, full screen, bulk selling. Next, in order: stairs, sword in hand plus a two-handed or alternating attack, cape weights, jump blending, configurable keys, then monster locomotion (starting with the skeleton's rig).
2. **Phase 2, world.** Smith inside, Guild Master's place, NPC bodies, floating trees, tents, grey slab, windmill rotation, training area.
3. **Phase 3, atmosphere.** Campfire, wind in the toon shader, ambient particles, animation polish.
4. **Phase 4, polish.** Body under 15k, NPC identities, town detail, menu styling, music (needs a licensing choice).

Monster locomotion is the largest item: it needs rigs and clips, so it is art work before it is code.

## What changed
- `GameTime.SetPaused`: the one owner of the clock can hold it at 0; hit-stop and Flash Time keep the time they had left. Camera and buff timers stop too.
- `PauseMenu` (Esc / Start): Resume, Settings, Controls, Audio, Graphics (full screen, resolution, v-sync), Character status, Return to main menu, Quit. Leaving asks first, can save, and stays if the save fails. It does not open on the death screen.
- Esc no longer opens the status window; Tab does, and the pause menu has a row for it.
- Shops: "Sell all monster cores" with a quote and a yes/no step, and 1 / 5 / 10 / all for any stack. Quest items are never sold.

## Known limits
- Riposte and parry windows run on real time, so a pause can end one.
- Returning to the main menu and loading again has no automated test.
- Buy-back remembers only the last few items, so a bulk sale cannot all be bought back.
