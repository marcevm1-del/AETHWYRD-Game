# 05 — Stats, Skills & Magic (v0.2)

## 1. Stats
| Stat | Effects | Soft cap feel |
|---|---|---|
| **STR** | Physical damage, carry weight, heavy weapon speed | 1 STR ≈ +1.5 phys atk |
| **VIT** | Max HP, DEF, poison/disease resist, stamina regen | 1 VIT ≈ +12 HP |
| **AGI** | Move/attack speed, dodge distance, evasion | Dodge frames scale up to +50% |
| **DEX** | Accuracy, crit rate, ranged damage, crafting quality | 1 DEX ≈ +0.1% crit |
| **INT** | Magic damage, max MP, spell learning slots | 1 INT ≈ +1.5 mag atk |
| **WIS** | MP regen, healing, magic resist, chant speed | — |
| **LUK** | Drops, crit damage, rare encounters, "lucky" procs | — |
| **CHA** | Prices, taming, companion loyalty, dialogue options, intimidation | — |

**Derived:** ATK, M.ATK, DEF, M.DEF, Crit %, Crit Dmg, Evasion, Poise (stagger resist), Carry Weight, Cast Speed.
**Hidden:** Karma (−1000 to +1000), Fame, Divine Favor (per god), Aether Saturation (Forbidden magic corruption meter).

## 2. Skill Families
| Family | Learned by | Example |
|---|---|---|
| **Class Skills** | Leveling a class | *Shield Bash* |
| **Weapon Arts** | Weapon mastery (any class) | *Crescent Moon Slash* |
| **Spells** | Spellbooks, trainers, scrolls, affinity | *Fireball* |
| **Life Skills** | Doing the activity | *Cooking Lv.7* |
| **Extra Skills** | Rare drops, feats, hidden teachers | *Detect Danger* |
| **Racial Skills** | Race | *Elven Grace* |
| **Monster Skills** | Predation, pacts, tamed monster links | *Fire Breath* |
| **Unique Skill** | Origin | *Predator* |
| **Titles** | Feats | *Goblin Slayer of Hollowpine* |

**Proficiency:** skills level **1–10 by use**. At Lv.10 → **Evolve** (stronger version) or **Fuse** (with another Lv.10 skill).
