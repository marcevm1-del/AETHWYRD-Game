## Class Change Rules (Q22)
- Changing **Main Class family** (e.g. Swordsman → Mage): a **Rebirth Sigil** (rare: deep Labyrinth or chase quests) + a large gold cost + **"Rebirth Trial"** quest + your new class starts at Advanced Lv 1 max (you never lose your character level).
- Skills from the old class are **kept** but only usable at 50% power unless they fit the new class.
- **Sub-Class** changes are cheaper (gold + a shrine quest), with a 7-day in-game cooldown.
