## Variant Modifiers (apply to any monster)
| Modifier | Visual cue | Effect |
|---|---|---|
| **Elite** | Gold nameplate, aura | +1 sub-rank, extra skill |
| **Named** | Unique model tweak, title | Unique skills, roams, evolves, remembers you |
| **Corrupted** | Red veins, smoke | +stats, dark element; purify for bonus loot |
| **Regional** | Palette swap | Element changes (Frost Goblin, Sand Wolf) |
| **Alpha** | Bigger, scarred | Leads pack, buffs nearby |
| **Ancient** | Moss, crystals growing on it | ×2 HP, ancient drops |
| **Blood Vesper** | Red glow (only under red moon) | +1 rank, rare loot |
| **Chroma** | Shimmering rare colors | Cosmetic; collectible; trophy |
| **Spirit-touched** | Translucent, blue | Phases; drops spirit essence |
